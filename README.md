# 🛠️ Sysadmin

Notes d'administration système : procédures, commandes et scripts d'usage courant, pour le réseau, la virtualisation, Windows, Linux et Microsoft 365.

Des notes de terrain, écrites pour être retrouvées vite. Elles ne remplacent pas la documentation officielle.

## 📑 Sommaire

Les dossiers suivent l'ordre de l'infrastructure, des fondations vers les usages.

| Dossier | Contenu |
|---|---|
| [🌐 01-reseau](01-reseau/) | Pare-feu WatchGuard, SMTP, impression, certificats |
| [📦 02-virtualisation](02-virtualisation/) | Proxmox, Docker |
| [🪟 03-windows](03-windows/) | PowerShell, sécurité, partages et permissions, services, sessions, outils |
| [🐧 04-linux](04-linux/) | Installation Debian, utilisateurs et droits, partages |
| [☁️ 05-microsoft-365](05-microsoft-365/) | Entra ID, Exchange Online, SharePoint, sécurisation d'un tenant |
| [🕵️ 06-pentest](06-pentest/) | Test d'intrusion, de la reconnaissance à l'élévation de privilèges |

## ⚠️ Avertissement

- Les commandes sont données telles quelles : les tester sur un environnement de test avant de les lancer en production.
- Le dossier [06-pentest](06-pentest/) ne sert que sur des systèmes personnels, en lab ou avec une autorisation écrite.
