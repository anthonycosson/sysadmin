# Configuration de Quest

## Choix des licences

* Microsoft entra ID for Devices : Besoin d'exporter manuellement les utilisateurs AD, Entra et les postes.
* ODM AD : La remonter des utilisateurs se fait automatiquement mais il y a un peu plus de configuration et la licence est plus cher.
